# Live world geography

Generated by `scripts/generate-world-map.mjs` from Natural Earth's 1:10m
country polygons, pinned at revision
`ca96624a56bd078437bca8184e78163e5039ad19` of
https://github.com/nvkelso/natural-earth-vector . Natural Earth data is public
domain: https://www.naturalearthdata.com/about/terms-of-use/ .

The generator caches source downloads in the OS temporary directory. The app
uses only the committed assets, with no geocoding requests for map interaction.
Regenerate with `npm run generate:world-map`.

Natural Earth 1 provides the familiar wide atlas layout used by the live map.
The map renders solid country silhouettes and national borders at every zoom
level. Labels follow this source's boundaries and names;
disputed boundaries and administrative naming are not universal or necessarily
current. Antarctica is intentionally omitted from the product view to preserve
the inhabited-world framing. Coast/country outlines are simplified within 0.12
projected units for display.
Visitor coordinates remain approximate IP locations and are separate from the
static geographic labels.

Country detail is generated separately with `npm run generate:regional-maps`.
Only the 44 standard Stripe seller markets plus South Africa receive maps.
Preview and other extended-network countries get live regional statistics only.
This is display coverage, not a Stripe payment-eligibility rule.

Assets in `public/maps/regions` load only when the country is opened. No runtime
D3, external map requests, map SDK, or extra Firestore listener is used.
Every view fits to the same 1000 x 500 canvas; remote territories have separate
fitted views rather than compressing the mainland. Country-specific conformal
projections retain local shapes. Shared topology is simplified once per arc
within 0.12 display pixels, then coordinates are rounded to 0.01 pixels.
These are cartographic display maps, not survey/legal boundary guarantees.

geoBoundaries gbOpen supplies most boundaries, with Italy/Greece level overrides.
Official Hong Kong district data, Kartverket's newer Norwegian counties, and
Eurostat/GISCO's 2024 Slovenian municipalities replace unsuitable general layers.
Gibraltar has no province/state tier and displays its single territory.
Per-country attribution, original licence, source URL, boundary ID/date are
retained in every asset and `sources.json`, and available in the detail UI.
Source years differ; current completeness is not guaranteed by the suppliers.
Regional totals match normalized source names and explicit aliases only.
Unmatched or unavailable regions remain visible in statistics, never guessed.

The interactive globe is a WebGL unit sphere with perspective projection,
latitude/longitude visitor positions and geographic surface picking. Its local
Earth texture uses the same pinned public-domain Natural Earth country source.
`scripts/generate-live-globe.mjs` writes simplified geographic rings and label
coordinates into `worldGlobe.json`; Antarctica is retained for the whole sphere.
Countries are coloured for configured markets and observed visitor activity.
No outside texture image or map service is requested. Devices without WebGL use
a Canvas ray-traced sphere, preserving rotation and country selection.
