# Report illustration assets

Generated with the built-in image generation tool. Transparent originals remain in the Codex generated image folder. Optimized 320×320 PNG copies are in `public/images/reports`.

Only report headings and inventory summaries use this artwork. Launcher, navigation, search controls and date controls retain their existing functional icons. Find category work is paused.

## Base prompt

Use case: stylized-concept. Asset type: small report heading icon for a white mobile commerce app. Create ONE original isolated object illustration: SUBJECT. Match the visual language of polished Uber Eats category illustrations: compact colourful 3D-like vector-clean object, slightly isometric three-quarter view, simple realistic silhouette, crisp edges, soft dimensional highlights, smooth matte surfaces, rich harmonious colour and just a very subtle contact shadow. Premium editorial app illustration, not an emoji, not an outlined line icon, not photorealistic. Subject fills roughly 76% of a square canvas with generous clear padding and is centred. Transparent background with genuine alpha, no background shape, no frame, no card, no labels, no typography, no watermark. No extra decoration. Keep all details legible at 64px.
